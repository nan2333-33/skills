# 视频/文生图模型能力边界（基于Seedance 2.0 Pro + Doubao Seedream实战总结）

## 一、视频模型（Seedance 2.0 Pro）

### 1.1 做不到或极不稳定

| 能力 | 实际表现 | 应对策略 |
|---|---|---|
| 单镜承载≥3个连续动作 | 后面动作细节严重失控，模型"遗忘"前面设定 | **拆镜**，每镜1-2个动作 |
| 同时遵守≥3条硬约束 | 约束互相竞争，服从率指数下降 | 精简到≤2条核心硬约束，其余靠参考图或拆镜 |
| 文字prompt压过参考图 | 参考图权重大于文字，参考图wink+文字写睁眼=wink | **换参考图**，不要硬写文字 |
| 精确数量控制 | "四匹马"可能出3-5匹，围巾颜色错位 | 接受误差；关键计数用后期或单独镜头 |
| 跨镜头自动连续 | 模型无镜头间记忆，末态首态必然对不上 | **首帧锚定**：提取上镜末帧做下镜first_frame |
| 角色精确站位/走位 | "A在B左边C在后方"空间关系易漂移 | 用首帧/构图参考图锚定；少角色同框 |
| 改一个细节其他不变 | 整体生成不是图层编辑，改一处别处也可能变 | 接受整体重生成，不要期望局部编辑 |
| 复杂物理精确性 | 碰撞力度、弹跳次数、弧线轨迹不可控 | 用参考视频/首帧锚定起始物理状态 |
| 精准微动作（wink/手指/表情） | 微动作像素占比太小，易做错（双眼眨/不眨/眨错） | **微动作单独一镜**或结尾特写镜 |
| 图中文字/字幕精确渲染 | 文字容易乱码变形 | 后期加字幕，不生成进画面 |
| 长镜>15s | 超出模型单镜上限 | 按模型上限拆镜 |

### 1.2 first_frame/last_frame 平台规则（硬约束）

- **设了first_frame或last_frame的镜头，materials列表里不能放任何参考图**
- 报错信息："first/last frame and reference frames cannot exist at the same time"
- 解决方案二选一：
  - **方案A（推荐）**：用first_frame/last_frame字段做首尾锚定，materials里不放任何参考图，角色外观完全靠文字+首尾帧已有内容约束
  - **方案B**：把首帧图作为普通参考图放入materials，不设first_frame字段，靠文字prompt"起始画面严格延续参考图X"约束（效果不如方案A稳定，但可以同时带其他参考图）

### 1.3 能做到但需要正确方法

| 能力 | 正确做法 |
|---|---|
| 单镜1-2个核心动作 | 每镜只安排1-2个动作，成功率高 |
| 质感/风格统一 | 第一镜用参考图+美术基准文字锚定，后续镜靠首帧延续 |
| 基础物理（掉落/碰撞/弹跳/单段飞行） | 单动作时表现好，多物理动作要拆镜 |
| 角色外观还原 | 有清晰参考图时还原度较高 |
| 首尾帧锚定衔接 | first_frame/last_frame做锚定，肉眼可无缝 |
| 镜头运动（推/拉/平移/环绕） | 匀速缓动表现好，快速甩镜不稳定 |
| 环境氛围/天气/光线 | 擅长，靠文字描述即可 |

### 1.4 比较擅长

- 氛围/光影/质感渲染（玻璃/金属/毛绒/果冻/毛毡的"感觉"）
- 单段流畅动作（一个东西掉落/飞出/滑过/漂浮）
- 镜头运动（缓慢推近/拉远/平移）
- 整体画面美感和色彩构图
- 粒子/光效/烟雾/火焰等氛围元素
- 场景建立和空间感

## 二、文生图模型（Doubao Seedream 等）

### 2.1 做不到

- **已有图上精确改一个细节**（"把眯眼改成睁眼其他不变"）= 等于重画，颜色/比例/造型/风格全漂移。文生图没有PS式的图层编辑/局部修改能力
- 严格按比例/尺寸/位置精确构图（能画"感觉对"的图，画不出像素级精确）
- 多个角色同框保持完全统一画风
- 图中文字/Logo精确渲染（容易乱码）
- 精确还原复杂IP的所有细节（能出"形似"，难出"一模一样"）
- 生成多角度一致的角色三视图（需要专门方法或多次抽卡）

### 2.2 能做到

- 从零生成一个风格统一的新角色/场景/物体
- 风格迁移（"换成赛博朋克风/水墨风/像素风"）
- 氛围图/概念图/参考灵感图/情绪板
- "长得像但不完全一样"的创意变体
- 海报/插画/封面等不需要精确还原的视觉内容
- 文字描述驱动的原创形象设计

### 2.3 使用原则

- **角色锚定图生成**：用`doubao-seedream-5-0-lite`模型，ratio=16:9（横版设定稿），纯白/浅灰底，多视角
- **不用于修改已有IP的局部细节**：需要"改眼睛/改颜色/改姿势"时，告知用户文生图做不到精修
- **画风一致性**：同一项目的所有锚点图用同一模型、同一美术基准描述生成

## 三、模型协作的正确预期

| 错误期望 | 现实 | 正确做法 |
|---|---|---|
| 一句话生成完美短片 | 需要分镜+参考图+多轮迭代+后期剪辑 | 按7步流程走，每步确认 |
| 改一个细节其他不变 | 视频整体重生成 | 接受迭代，或用后期合成 |
| 所有角色跟官方一模一样 | 每个角色要有清晰参考图，每镜角色不超过4个 | 准备高清参考图，多角色拆镜 |
| 一镜到底又有细节又流畅 | 15秒一镜能出氛围，多动作细节必丢 | 要细节就多镜快切 |
| 模型理解我的创意意图 | 模型理解prompt字面意思 | 把意图拆解成具体画面描述 |
| 文生图能修图 | 文生图是重画不是修图 | 精修用后期/PS，或接受重绘 |
| 加强prompt措辞就能解决问题 | 硬约束超过3条就开始丢 | 换策略（拆镜/换参考图/后期）而不是堆形容词 |

---

## 核心结论

当前视频生成模型本质是**"高级动画草图+氛围渲染器"**，不是精确动画制作工具。
- 擅长：快速产出有氛围、有感觉、有美感的画面
- 不擅长：精确控制（数量/位置/细节/微动作/多动作序列）

做好片子的方法论：
1. **分镜拆细**（每镜动作少，2-4s/镜）
2. **参考图锚定**（每个核心角色/产品有清晰参考图）
3. **首帧衔接**（上镜末帧做下镜首帧）
4. **多轮迭代**（接受2-3轮调整）
5. **后期合成**（字幕/音效/精修用后期，不指望模型一次到位）
