# 分镜拆分原则与镜头语言规范

## 一、镜头拆分原则

### 1.1 单镜动作上限

**铁律：每个镜头只承载1-2个核心动作。**

错误示范（本次项目踩坑）：
- 8s镜头塞了"坠落+碰撞+产品A弹出+角色B飞出"4个动作 → 后面的产品A和角色B动作失控
- 7s镜头塞了"4匹马依次跳出+列队+推近+wink+黑场"5个动作 → 马的数量和颜色错位

正确拆分（以15s短片为例）：
- 镜1（2-3s）：两方块坠落碰撞立定（核心动作：坠落+碰撞）
- 镜2（2-3s）：产品A弹出滚定（核心动作：弹出+滚动）
- 镜3（2-3s）：角色B飞出落地（核心动作：飞出+落地）
- 镜4（3-4s）：四匹马依次跳出列队（核心动作：连续出场+列队）
- 镜5（2-3s）：推近wink黑场（核心动作：推近+wink+黑场）

### 1.2 时长与镜头数的关系

**关键认知：短时长≠少镜头，恰恰相反。**

- 15s以内短片：推荐4-6个镜头，每镜2-4s快切，节奏干脆，每个动作单独给镜，精度高
- 15-30s：推荐4-8个镜头
- 30s以上：按动作段落拆，每段2-5s

**节奏两种选择（必须给用户选）：**
- **长镜头流派**：每镜5-10s，氛围连贯、镜头感强，但细节精度下降
- **快切流派**：每镜2-4s，精度高、节奏明快，但需要后期保证衔接流畅

### 1.3 角色数量控制

- 单镜出场角色不超过3-4个（含道具/方块等非人物元素）
- 群像/全家福单独给一镜，不要在动作镜里同时安排站位
- 新角色出场单独给镜，不要多个角色在同一镜首次出场

### 1.4 模型时长上限

- Seedance 2.0 Pro：单镜4-15s
- 规划时长时先确认当前可用模型的上限
- 最少镜数 = ceil(总时长 / 单镜上限)，但这只是下限，实际镜数应该更多以保证精度

## 二、跨镜衔接规划

**分镜阶段必须设计每镜衔接方式，不能等生成完才想怎么拼。**

### 2.1 衔接方式

| 衔接方式 | 说明 | 适用场景 |
|---|---|---|
| **首帧锚定（最可靠）** | 提取上镜末帧做下镜first_frame | 同一场景连续动作，必须无缝衔接 |
| 动作衔接 | 上镜末态动作开始，下镜继续完成 | 飞行中、运动中的动作延续 |
| 情绪/氛围衔接 | 两镜氛围/光线/色调一致，主体可切换 | 场景转换、视角切换 |
| 硬切 | 直接切，不做特殊衔接 | 节奏性强、刻意跳切 |
| 转场特效 | 溶解/黑场/白闪/模糊 | 时间/空间/段落转换 |

### 2.2 末态描述

每个镜头prompt必须包含明确的**末态描述**（末帧画面是什么样的）：
- 每个角色/物体的位置
- 姿态（站定/飞行中/面向镜头）
- 画面构图
- 光线和氛围

这既是给模型的约束，也是下一镜首帧锚定的参考依据。

### 2.3 连续性合同（continuity_context）

写prompt时使用统一的连续性描述块：

```
【前镜末态/本镜起始】：具体描述画面起始状态
【本镜末态】：具体描述画面结束状态
【scene_anchor】：固定不变的元素（如背景、桌面位置、光源方向）
【inherited_props】：从上镜继承的道具/角色及其位置
```

## 三、镜头语言规范

### 3.1 景别+机位格式

使用统一格式：`【景别，机位/运镜】`

景别：
- 大远景/远景：环境为主
- 全景：人物全身+环境
- 中景：人物膝盖/腰部以上
- 近景：胸部以上
- 特写：面部/局部细节
- 大特写：眼睛/手指等极局部

机位：
- 正面平视/侧面/俯视/仰视/45度斜侧
- 固定/手持/轨道/斯坦尼康

运镜：
- 推（dolly in/zoom in）/拉（dolly out）
- 平移（pan left/right）
- 升降（crane up/down）
- 环绕（orbit）
- 跟拍（follow/track）

### 3.2 分时序写作

每个镜头的prompt必须按时间分段，标注时间区间：

```
【0-2.5s】：具体描述这段时间发生什么
【2.5-5s】：具体描述这段时间发生什么
【5-8s】：具体描述这段时间发生什么
```

每段只描述1-2个核心动作，不要堆太多。

### 3.3 声画同刻

声音描述写在对应时间段内，同步画面动作：
- 环境声：背景音
- 动作音效：撞击声、弹出声、喷气声
- 人声/对白：角色说什么
- 音乐节奏点：配合动作的节拍

### 3.4 Prompt结构模板

```
[美术基准段]：质感、色板、光线、风格、渲染方式，固定复用
[参考图用途段]：[@图片1]是什么，[@图片2]是什么，每张图约束什么
[起始空间段]：画面起始状态（首帧锚定时与首帧一致）
[分时序段]：
  【X-Ys】动作+声音
  【Y-Zs】动作+声音
[末态段]：画面最终状态，用于衔接下一镜
[硬约束段]：必须/关键/注意事项（不超过3条）
```
